This experiment is frozen before its new policy evaluations. It uses existing, already researched historical data. No new independent forward-performance claim follows from these results.

Reuse the full Coinbase snapshot and original immutable teaching corpus from the completed broad study. ## Matched teaching

Use both seeds 7 and 41. For each, compare original asset-grouped raw rewards, globally shuffled paired raw rewards, and the identical shuffled pairs with the target changed to long-over-cash log-wealth advantage. Each context has both actions and identical initial account and observed price path. Shared market movement, paid costs and exit-reserve changes must reconcile to the actual relative wealth. Retain all gains, losses and ties.

Each arm uses the actual pinned Core SpongeDQN, with the same 43 inputs, two actions, 64-row full-batch replay, gamma0, architecture, learning rate, number of examples and update budget. The grouped control's entire training state must equal the existing cached implementation. Raw-shuffled and advantage-shuffled arms share one lesson order per seed. Every supplied row must reach an actual gradient batch; row counts alone do not certify that.

Measure fixed sentinel panels from four source-order quartiles before and after training quarters. These diagnose fitting and retention of supplied cases. They are not held-out market tests, and source order is not calendar age.

## Bounded, consumed memory

Use the existing PatternMemory comparison, with an unbiased fixed reservoir of at most128 cases for each of sixteen regimes defined solely by visible exposure, 200-day trend, volatility and order-budget ratio. At most2,048 active cases fit in one two-character dictionary page. All original cases remain in the immutable corpus and new matched-lesson archive. Do not select only profitable memory cases.

For each decision, retrieve up to32 nearest mature cases. Exclude the current asset from both the case source and the outcome-label source. When at least16 cases exist and normalized squared distance is at most1, use a fixed 75% neural action advantage and 25% recalled mean advantage. Otherwise use the neural prediction. Memory-only and label-shuffled recall are explicit controls. Neighborhood size is not an independent sample count; cases remain correlated.

Frozen memory comparisons share exactly the same learned neural weights. Full decision receipts record the actual consumed two-character case and label codes, regime, distance, maximum evidence availability time, mean recalled advantage, neural advantage, combined value and memory hash. The reversible legend links each code to its original source IDs, file hash, outcome and accounting explanation. Recovered memory must return exactly the same case references and values.
